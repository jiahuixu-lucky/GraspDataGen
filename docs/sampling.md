# 候选多样性与恢复

采样在物体原始坐标系中进行。接触点使用按三角形面积映射的四维 scrambled
Sobol 序列，四个分量分别决定三角形、三角形内的两个坐标和绕接触轴的角度
相位。各轮连续推进同一序列，不重新生成独立随机点云；区域标注仍通过三角形
面积权重限制可采样表面。每个接触的多个 roll 保持等角间隔。

候选按接触中点的空间区域交错排列，先访问不同位置，再取同一区域的其他
接触和方向。距质心的距离只用于同一覆盖层内排序，不再全局优先挤满质心
附近的候选。物体、夹爪、接近路径和姿态的几何约束保持原样。

物理验证前记录目标 TCP 位姿和接触宽度的精确指纹。在固定的夹爪、物体与
采样配置下，它们确定接近位姿、开口选择和闭合命令；完全相同的输入不会
跨批、跨轮反复验证。输入指纹不含随轮次变化的 candidate ID。

近邻覆盖使用目标 TCP 位置、规范化四元数和接触宽度分格，位置与宽度采用
最终去重的分辨率，四元数采用对应角度的弦长。分格只是控制探索投入，并不
宣称同格的姿态等价。每个区域的累计验证数加上累计合法成功数不得超过当前
轮次，才允许再次取样：第零轮允许一次，此后每轮增加一次额度，未消费的
额度可以累积。因此新发现或很少访问的区域有更多探索机会；失败只消耗一次
额度，成功额外消耗一次，优先把预算留给尚未覆盖的区域。已通过几何筛选并选入
当前批次的候选立即占用访问次数，避免同一批内重复填充。

几何拒绝不会占用区域访问次数。成功反馈取自物理验证和实际闭合姿态检查，
包括后来因实际姿态相近而被去重的成功候选。失败附近没有永久禁采半径。
最终发布仍按实际闭合 TCP 位姿及开口去重，物理验收阈值未因此调整。
更分散的候选可能降低原始物理通过率；效果应按相同仿真预算和运行时间内
最终新增的独立成功数评估，而非只比较去重前的通过总数。

每批的 `sampling-*.npz` 保存所有实际验证候选的指纹、覆盖格和成功反馈；
`manifest.json` 的 `sampling_shards` 与抓取分片在同一 checkpoint 确认。
恢复时校验分片哈希、结构和总验证数，重建访问记录，再从保存的 round/cursor
继续采样。未确认的分片不参与恢复，也不消耗候选预算。

manifest 新增两个采样统计：`candidate_duplicates` 是精确重复输入剔除数，
`coverage_deferrals` 是当前区域访问额度已用尽而暂缓的候选数。
`duplicates` 仍仅表示物理验证后的实际闭合姿态去重数；`attempted` 仍只计
实际执行物理验证的候选。覆盖分格有边界效应，也不能消除不同目标姿态在
闭合过程中收敛到相近姿态的情况，因此最终去重依然必需。

实现变化后应使用新的输出目录。现有数据可继续回放，但不能将旧任务的
采样状态当作含有覆盖记录的新任务续跑；现有实现身份校验会阻止这种混用。
