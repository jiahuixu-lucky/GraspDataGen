# 候选采样与恢复

在物体原始坐标系中，用连续推进的四维 scrambled Sobol 序列选择三角形、
面内接触点及 roll 相位；三角形按面积加权，区域标注限制可采样表面。
同一接触的多个 roll 等角分布，候选按空间区域交错排列以扩大覆盖。

物理验证前，按目标 TCP 位姿和接触宽度的精确指纹去除重复输入。
近邻覆盖按 TCP 位置、四元数及接触宽度分格：每格每轮增加一次访问额度，
验证消耗一次，成功额外消耗一次；几何拒绝不消耗额度，失败不会永久禁采。
最终仍按实际闭合 TCP 位姿及开口去重，覆盖分格不能替代最终去重。

每批 `sampling-*.npz` 保存输入指纹、覆盖格和成功反馈，与抓取分片一起
提交 checkpoint。恢复时校验分片并重建访问记录，从保存的 round/cursor
继续；未提交分片不参与恢复或预算统计。

| manifest 统计 | 含义 |
| --- | --- |
| `candidate_duplicates` | 物理验证前剔除的精确重复输入 |
| `coverage_deferrals` | 覆盖格额度耗尽而暂缓的候选 |
| `duplicates` | 物理验证后按实际闭合姿态去重的数量 |
| `attempted` | 实际物理验证的候选数 |

采样效果应比较相同预算下新增的独立成功数。恢复条件见[运行说明](installation.md)。
